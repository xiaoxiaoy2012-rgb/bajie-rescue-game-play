# 八戒搬救兵

一款水墨风格的单人护送布阵小游戏。玩家需要招募并培养不同类型的救兵，抵御沿途伏击，护送师傅安全通过西行驿路。

## 在线试玩

[点击开始游戏](https://xiaoxiaoy2012-rgb.github.io/bajie-rescue-game-play/)

支持电脑浏览器和手机浏览器。

## 游戏玩法

1. 从救兵驿站提供的三个选项中选择一名救兵。
2. 将救兵拖入地图上的白色阵位。
3. 两个同兵种、同等级的救兵可以拖到一起合并升级。
4. 备战栏内的救兵可以直接合并，也可以与阵位上的救兵合并。
5. 收集三枚援印，可以获得完整武将。
6. 根据伏击路线调整阵容，保护师傅继续前进。
7. 守住六波伏击，并护送师傅通过三个驿站即可获胜。

## 操作方式

- 电脑：使用鼠标拖拽救兵。
- 手机：用手指按住并拖动救兵。
- 点击暂停按钮可以暂停或继续战斗。

## 游戏特色

- 单人三路护送玩法
- 四类救兵与合并升级系统
- 七套主题场景与首领
- 水墨长卷风格画面
- 支持鼠标和触屏操作
